# 협업 기록 — 2026-10-17 (세 모델 오케스트레이션)

Roundtable v2를 세 공급사 모델이 나눠 만들었다. 작업 지시·리뷰 요청은 모두 Roundtable 자신의 방(write·read 모드)으로 했다. 사람은 목표와 제약만 줬다.

## 역할

| 역할 | 모델 | 맡은 일 |
|---|---|---|
| 오케스트레이터 | Claude Opus 5.5 (Claude Code) | 설계 브리프, 작업 분배, 결정, 공급사별 추론 노력·Gemini 한도 훅·agy 읽기 전용 수정 구현, 병합, 실제 CLI·브라우저 검증, 공개 |
| 백엔드 구현 | GPT-6.1 Sol (Codex, effort high) | 참가자별 독립 실행 스케줄러 |
| UI 구현 | Gemini 4 Argon (Antigravity, high) | 디자인 브리프 기반 UI v2 |
| 독립 리뷰 | 서로 바꿔서 | Argon → 백엔드 리뷰, GPT → UI 리뷰 |
| 웹 조사 | GPT-6.1 Sol | agy statusLine 공식 문서, OAuth 정지 근거, 참고 UI |

원칙: **작성자와 다른 공급사가 리뷰한다.** 같은 모델은 자기 출력에 관대하다는 커뮤니티 관찰과, 생성·검토를 다른 모델이 나누는 구성이 설계 품질을 높였다는 연구(LLM Consortium for Software Design Refinement, 2026)를 따랐다.

## 흐름

```
사람 요구 ──▶ Claude: 디자인 브리프(JTBD·휴리스틱·데이터 계약·수용 기준) + worktree 2개
             ├─▶ GPT: 백엔드 스케줄러 ──▶ Argon 리뷰(6건) ──▶ Claude 결정 A~F ──▶ GPT 수정
             ├─▶ Argon: UI v2 ──▶ GPT 리뷰(7건) + Claude 브라우저 검수(5건) ──▶ Argon 수정
             ├─▶ GPT: 웹 조사 ──▶ Claude: Gemini 한도는 OAuth 대신 공식 statusLine 으로 결정
             └─▶ Claude: 추론 노력·한도 훅·agy 읽기 전용 결함 ──▶ 병합 ──▶ 실제 CLI·브라우저 검증 ──▶ 공개
```

## 결정과 근거

| 쟁점 | 결정 | 근거 |
|---|---|---|
| Gemini 사용량 출처 | agy 공식 statusLine 이 넘기는 JSON만 저장 | 사용자 경고 + GPT 조사: Antigravity 추가 약관 6항이 서드파티의 OAuth 사용을 정지 사유로 명시. statusLine 은 공식 문서가 안내하는 확장 |
| 대기열 설계 | 대화 복사본을 얼리지 않고 "볼 수 있는 마지막 메시지 번호(cap)"만 보관, 실행 직전 프롬프트 생성 | Argon 리뷰 1·2·5·6번이 모두 큐 진입 시점 복사에서 비롯됨 |
| 빈 턴 | 새로 전달할 것이 없는 일반 턴은 CLI를 부르지 않음 | 우선 메시지가 일반 몫을 함께 가져간 뒤 '(없음)' 턴이 돌던 문제 |
| 토론 중 일반 메시지 | 토론이 끝날 때까지 대기 | 토론 순차성 유지(리뷰 3번) |
| agy read 모드 | `--disable-slash-commands`는 write 에만 | 같이 쓰면 plan 이 무시되어 파일이 써짐을 실측 |

## 리뷰가 찾은 것

- **Argon → GPT 백엔드(6건)**: 완료된 답이 '작성 중'으로 박제되어 다음 턴에 안 보임, 우선 턴 뒤 빈 턴 실행, 미전달 조정 유실, 토론 중 일반 턴 병렬, 참가자 상태 불일치, 대기 턴마다 프롬프트 재생성(대기 32개 기준 pump 호출당 할당 약 2,520 → 수정 후 14).
- **GPT → Argon UI(7건)**: 마크다운 링크 `javascript:` XSS(이전 버전부터 있던 문제), 위로 스크롤 중 DOM 상한 미적용, 작업 기록 조회 실패 캐시, 자동 펼침이 수동 접기를 되돌림, 스트리밍 중 기록 전체 재생성, 참가자 패널 재생성으로 포커스 손실, 멘션 후보 접근성 연결 누락.
- **Claude 브라우저 검수(5건)**: 새 방 버튼 잘림, 공급사 패널 겹침, 좁은 폭 머리 영역 과대, 없는 한도 창의 '-' 표시, 긴 한도 라벨 줄바꿈.
