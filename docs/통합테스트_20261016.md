## 테스트가 찾아낸 결함과 수정

1. **턴 실패 시 메시지 유실** — 토론 중 Claude와 Antigravity가 `hub.go`를 읽고 지적함: `deltaFor`가 프롬프트를 만들 때 `LastSeen`을 올리는데 실행이 실패해도 되돌리지 않아, 실패한 에이전트는 그 턴의 메시지를 다시 받지 못했다. → `prepared.prevSeen`을 보관했다가 `done`이 아니면 복원하고, 그 사이 실행 중 주입(`Live`)된 메시지도 다시 전달 대상으로 되돌린다. 단위 테스트 `TestFailedTurnRedeliversMessages` 추가.
2. **Codex 세션 재개 인자** — `codex exec resume`은 `--color`·`--cd`를 받지 않고 옵션을 세션 ID 앞에 둬야 한다. → `codexArgs` 수정, 테스트 `TestArgsPerMode` 갱신.
3. **Codex 실행 파일 선택** — PATH의 `%LOCALAPPDATA%\OpenAI\Codex\bin\codex.exe`에는 `codex-code-mode-host.exe`가 없어 모델이 code-mode 도구를 고르면 "Code Mode is unavailable"로 실패하고 파일을 못 읽었다고 포기하는 턴이 있었다. npm `codex.cmd` 뒤의 동봉 exe에는 host가 있다. → PATH를 순서대로 걷고 npm 셸 스크립트를 만나면 동봉 exe로 바꾸는 `resolveCommand`로 교체, 테스트 `TestResolveCommandPrefersNpmVendoredExe` 추가. code-mode 경고는 오류가 아닌 상태 줄로 표시.
4. **병렬 배치의 스냅샷 불일치** — 같은 사용자 메시지를 받은 두 에이전트 중 빠른 쪽의 답이 느린 쪽의 프롬프트에 섞여 들어갔다. → 배치 전체의 프롬프트를 한 락 안에서 먼저 만들고(`prepareTurn`) 그 다음 병렬 실행.
5. **UI** — `#room`의 `display:flex`가 `hidden` 속성을 덮어 빈 화면과 방 화면이 겹쳐 보였다. → `[hidden]{display:none}` 추가.
