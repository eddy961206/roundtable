    CLI 설치 상태

    실행 프로그램을 찾았는지만 확인해. 로그인·구독 여부는 별도로 확인해야 해.

    Roundtable — 멀티 에이전트 코딩 단톡방

    이용 중인 CLI나 연결한 API 모델을 참가자로 추가하세요. 같은 공급사의 서로 다른 모델도 각자 독립된 대화로 질문하고 토론할 수 있습니다.

    1. @멘션과 동시 호출

    입력창에 @를 입력하고 이름을 선택하세요. 한 명만 부르려면 아래 대상 버튼을 누르면 됩니다. 멘션 없이 보내면 활성 참가자 전원이 동시에 답합니다.

    2. 1회성 조정 (Steering)

    입력창의 대상 칩으로 한 에이전트만 지정해 방향을 바꿉니다. Claude는 실행 중 즉시 주입되고, Codex·Antigravity는 현재 턴 직후 우선 전달됩니다. 전송 후 자동으로 전체 대상으로 복귀하며 Esc로 해제합니다.

    3. 구조화된 라운드 토론

    상단 토론 시작을 누르면 N라운드 동안 순서대로 발언하며 CONTINUE · AGREE · PASS · CONCLUDE 신호를 남깁니다. 전원 동의/패스하거나 결론이 나면 자동 종료됩니다.

    4. 방 단위 권한 모드

    read 작업 폴더 읽기·검색·서브에이전트 탐색(기본)
    chat 대화 중심 · 프로젝트 폴더를 전달하지 않음
    write CLI 작업 폴더 편집 허용

    예시 프롬프트 (방을 만든 뒤 눌러서 바로 입력)

    단축키: Enter 전송 · Shift+Enter 줄바꿈 · Esc 대상 해제/팝업 닫기 · Ctrl+. 모두 중지 · / 입력창 포커스

      새 방

      참가자 구성

      이용 중인 공급사와 인원을 선택하세요. CLI 설치 여부는 로그인·이용 권한과 다를 수 있습니다.

      참가자 추가

      같은 모델도 여러 명 추가할 수 있습니다. 각자 별도의 대화를 이어갑니다.

      작업 계획

      write 방에서 파트별 worktree·교차 리뷰(다른 공급사 좌석)·통합 branch 병합을 시작합니다.

      검증 명령 (Verify)

      병합 시 통합 worktree에서 순서대로 실행합니다. argv는 셸 문자열이 아닌 공백 구분 인자 배열로 전달됩니다.

      파트 분할 (Parts)

      리뷰어 좌석은 담당 좌석과 다른 공급사(Provider)의 활성 좌석만 선택할 수 있습니다.
