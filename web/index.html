    Roundtable — 멀티 에이전트 코딩 단톡방

    이용 중인 CLI나 연결한 API 모델을 참가자로 추가하세요. 같은 공급사의 서로 다른 모델도 각자 독립된 대화로 질문하고 토론할 수 있습니다.

    1. @멘션과 동시 호출

    입력창에 @를 입력하고 이름을 선택하세요. 한 명만 부르려면 아래 대상 버튼을 누르면 됩니다. 멘션 없이 보내면 활성 참가자 전원이 동시에 답합니다.

    2. 1회성 조정 (Steering)

    입력창의 대상 칩으로 한 에이전트만 지정해 방향을 바꿉니다. Claude는 실행 중 즉시 주입되고, Codex·Antigravity는 현재 턴 직후 우선 전달됩니다. 전송 후 자동으로 전체 대상으로 복귀하며 Esc로 해제합니다.

    3. 구조화된 라운드 토론

    상단 토론 시작을 누르면 N라운드 동안 발언하며 CONTINUE · AGREE · PASS · CONCLUDE 신호를 남깁니다. 블라인드 1R을 켜면 1라운드는 서로의 답을 보지 않고 동시에 답하고, 2라운드부터 공개해 순서대로 갈린 쟁점을 다룹니다. 전원 동의/패스하거나 결론이 나면 자동 종료됩니다. AGREE는 의견 일치일 뿐 검증이 아닙니다.

    4. 방 단위 권한 모드

    read 작업 폴더 읽기·검색·서브에이전트 탐색(기본)
    chat 대화 중심 · 프로젝트 폴더를 전달하지 않음
    write CLI 작업 폴더 편집 허용

    5. 작업 계획과 파트 분배

    write 방에서 작업 계획을 열고 목표·검증 명령·파트를 정하면, 파트마다 담당 좌석이 자기 worktree에서 작업하고 통합 branch로 병합됩니다. 진행은 상단 작업 보드에서 봅니다.

    6. 적대적 교차 리뷰

    파트가 끝나면 다른 공급사의 좌석이 diff를 리뷰합니다. 지적 → 작성자 답변 → 반박 → 재확인 순서로 라운드가 돌고, 통과한 뒤에야 병합됩니다. 지적·수정·철회 수는 더보기 ▾ 모델 기록에 쌓입니다.

    7. 참가자 간 요청

    에이전트는 응답 끝에 [[REQUEST:@이름]] 확인할 내용으로 서로에게 일을 넘기고, 받은 쪽은 [[REQUEST_DONE:…]]로 끝냅니다. 오른쪽 요청 목록에서 진행 상태를 봅니다.

    8. 이미지 공유

    입력창에 이미지를 붙여넣거나 끌어놓으면(PNG·JPEG·WEBP) 모든 참가자가 봅니다. 에이전트도 화면 캡처를 [[ATTACH:파일.png]]로 올릴 수 있어 UI 작업의 시각 검토를 다른 좌석에 요청할 수 있습니다.

    9. 역할 카드

    참가자마다 역할(예: 큰 그림·UX, 적대적 검증)을 정하면 모든 안내문에 들어갑니다. 역할은 "이 관점을 먼저 깊게 본다"는 우선순위이지 다른 문제를 말하지 말라는 뜻이 아닙니다. 프리셋과 모델 추천은 서버의 역할 파일에서 옵니다.

    10. 결정 카드

    결정은 오른쪽 결정 목록에 근거·남은 반대·미확인 항목과 함께 남습니다. 에이전트가 [[DECISION: 결정 | 근거: … | 반대: … | 미확인: …]] 한 줄로 적은 카드는 제안으로 기록되고, 사람이 확정하거나 거절합니다. 사람이 직접 추가한 결정은 바로 유효합니다. 유효한 결정 문장만 다음 턴부터 모든 참가자의 안내문에 들어갑니다.

    예시 프롬프트 (방을 만든 뒤 눌러서 바로 입력)

    단축키: Enter 전송 · Shift+Enter 줄바꿈 · Esc 대상 해제/팝업 닫기 · Ctrl+. 모두 중지 · / 입력창 포커스

          참가자 구성

          이용 중인 공급사와 인원을 선택하세요. CLI 설치 여부는 로그인·이용 권한과 다를 수 있습니다.

          결정 추가

          유효한 결정 문장은 다음 턴부터 모든 참가자의 안내문에 들어갑니다. 근거·반대·미확인은 화면에만 남습니다.

          참가자 추가

          같은 모델도 여러 명 추가할 수 있습니다. 각자 별도의 대화를 이어갑니다.

          작업 계획

          write 방에서 파트별 worktree·교차 리뷰(다른 공급사 좌석)·통합 branch 병합을 시작합니다.

          검증 명령 (Verify)

          병합 시 통합 worktree에서 순서대로 실행합니다. argv는 셸 문자열이 아닌 인자 배열(한 줄에 인자 1개)로 전달됩니다.

          파트 분할 (Parts)

          리뷰어 좌석은 담당 좌석과 다른 공급사(Provider)의 활성 좌석만 선택할 수 있습니다.

          모델 기록

          공급사·모델·추론 수준·역할별로 턴 수, 오류, 응답 시간 중앙값, 토큰, 파트·리뷰 결과를 모읍니다. 열 제목을 누르면 정렬됩니다. 추천은 사람이 하며 이 표는 근거일 뿐입니다.
